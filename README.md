# Дрыги ↗

Календарь спортивных событий на Балканах: даты, города и ссылки на организаторов.

Компактный и широкий вид, фильтры по странам и видам спорта. По умолчанию выбрана Сербия. Многодневные события показаны полосками, прошедшие дни приглушены.

## Содержимое

- `dist/` — готовый статический сайт.
- `dist/data/events.json` — база событий, которую мы обновляем вручную.
- `.github/workflows/calendar.yml` — публикация сайта в GitHub Pages после push в `main`.

Охват неполный; перед поездкой проверяй дату и место на странице организатора.

Для локального просмотра: `python3 -m http.server 4173 --directory dist`.
